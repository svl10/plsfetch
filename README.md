
# plsfetch

A fast and customizable system fetching tool written in Rust. Similar to neofetch and fastfetch.
<br>

## Installation

Install plsfetch with cargo

- Clone this repository
```bash
  git clone https://github.com/svl10/plsfetch.git
  cd plsfetch
```
- Install using cargo
```bash
  cargo install --path .
  ```

- Run plsfetch
```bash
  plsfetch
```
